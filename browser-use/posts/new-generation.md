# How New Generation uses Browser Use to Make the Web Ready for Agents

**Author:** Luka Secilmis
**Date:** 2026-03-17
> How New Generation uses Browser Use to score e-commerce sites for agent readiness.

---

AI agents are already browsing the web at scale — searching, comparing products, and making purchase decisions on behalf of users. That shift is only accelerating, and [New Generation](https://www.new-gen.ai) is building the tools that help brands prepare for it.

## Kepler and Agent Score

Kepler, New Generation's agentic commerce platform, helps brands understand how AI agents experience their sites and where those journeys break down. Its Agent Score evaluates how well a site supports AI-driven shopping by measuring how effectively an agent can access, navigate, and reason over product and site information across real commerce workflows.

## Powered by Browser Use

Agent Score runs on Browser Use, the browser automation infrastructure behind the emergence of web agents. New Generation uses it to launch hundreds of concurrent browser sessions against live brand sites, testing agent readiness at scale across realistic shopping tasks.

Since February alone, New Generation has run over **120,000 Browser Use tasks** — and that number is growing fast.
