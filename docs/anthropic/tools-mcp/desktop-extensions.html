🚨 MCP 安装痛点

MCP 协议发布后，开发者构建了大量本地 MCP 服务器，让 Claude 可以访问文件系统、数据库等。但反馈一致：安装流程太复杂。用户需要开发者工具、手动编辑配置文件，还经常被依赖问题卡住。

📦 .mcpb 包结构解析

Desktop Extension 本质上是一个 ZIP 压缩包，包含 MCP 服务器代码和一个 manifest.json 元数据文件。Claude Desktop 和其他支持 MCPB 的应用程序通过 manifest 了解一切所需信息。

📁 通用 .mcpb 结构

extension.mcpb (ZIP archive) ├── manifest.jsonREQUIRED — 扩展元数据和配置 ├── server/ — MCP 服务器实现 │ └── [server files] ├── dependencies/ — 所有依赖包/库 └── icon.pngOPTIONAL — 扩展图标

🔷 Node.js Extension

extension.mcpb ├── manifest.json ├── server/ │ └── index.js ├── node_modules/ ├── package.json └── icon.png

🐍 Python Extension

extension.mcpb ├── manifest.json ├── server/ │ ├── main.py │ └── utils.py ├── lib/ ├── requirements.txt └── icon.png

⚙ 内置运行时

Claude Desktop 自带 Node.js 运行时，无需用户安装任何外部依赖即可运行扩展。

🔄 自动更新

当新版本可用时，Extensions 会自动更新，无需手动重新下载安装。

🔒 安全密钥存储

API Key 等敏感配置自动存储在操作系统 Keychain 中，不会明文写入配置文件。

📜 Manifest 配置详解

manifest.json 是 Desktop Extension 的核心描述文件。它包含人类可读信息（名称、描述、作者）、功能声明（tools、prompts）、用户配置和运行时需求。

📝 最小 Manifest

只需 manifest.json 即可创建一个有效的 Desktop Extension：

{ "mcpb_version": "0.1", "name": "my-extension", "version": "1.0.0", "description": "A simple MCP extension", "author": { "name": "Extension Author" }, "server": { "type": "node", // "node" | "python" | "binary" "entry_point": "server/index.js", "mcp_config": { "command": "node", "args": ["${__dirname}/server/index.js"] } } }

🔑 用户配置与安全密钥

通过 user_config 声明需要用户提供的配置。Claude Desktop 会自动生成友好的配置 UI，验证输入，并将敏感值安全存储在 OS Keychain 中。

"user_config": { "api_key": { "type": "string", "title": "API Key", "description": "Your API key for authentication", "sensitive": true, // 自动存入 OS Keychain "required": true // 未提供前扩展不会启用 }, "allowed_directories": { "type": "directory", "title": "Allowed Directories", "multiple": true, "default": ["${HOME}/Documents"] } } // 在 server 配置中使用模板引用： "env": { "API_KEY": "${user_config.api_key}" }
📄
string

文本输入。可标记 sensitive 自动加密存储。

📁
directory

目录选择器。支持 multiple 多选。

🔢
number

数值输入。支持 min/max/default 约束。

🛠
tools / prompts

声明扩展提供的工具和 prompt 模板。

🚀 构建与安装流程

从现有 MCP 服务器构建 Desktop Extension 只需三条命令。安装同样简单 -- 拖放或双击即可。

🔧 开发者构建流程

Step 1: 初始化 Manifest
运行 npx @anthropic-ai/mcpb init，交互式工具会询问你的服务器信息并生成完整的 manifest.json。可使用 --yes 参数快速生成最基本配置。
Step 2: 配置用户输入
在 manifest 中声明 user_config，定义 API Key、目录等用户需要提供的配置。Claude Desktop 会自动生成友好的配置 UI。
Step 3: 打包扩展
运行 npx @anthropic-ai/mcpb pack 验证 manifest 并生成 .mcpb 归档文件。
Step 4: 本地测试
将 .mcpb 文件拖入 Claude Desktop 的 Settings 窗口。可以看到扩展信息、所需权限和 "Install" 按钮。

💡 高级特性

Desktop Extensions 支持跨平台适配、动态配置模板和功能声明，让扩展可以适应不同环境和使用场景。

🌏 跨平台支持

通过 platforms 字段为不同操作系统提供特定配置：

"mcp_config": { "command": "node", "args": ["${__dirname}/server/index.js"], "platforms": { "win32": { "command": "node.exe", "env": { "TEMP_DIR": "${TEMP}" } }, "darwin": { "env": { "TEMP_DIR": "${TMPDIR}" } } } }

📄 Template Literals

${__dirname} -- 扩展安装目录
${user_config.key} -- 用户提供的配置
${HOME}, ${TEMP} -- 系统环境变量

🛠 功能声明 (Tools)

在 manifest 中声明 tools 和 prompts，让用户在安装前就能了解扩展提供的能力。

📊 兼容性声明

指定 Claude Desktop 最低版本、支持平台（darwin/win32/linux）和运行时版本要求。

🛠 Tools & Prompts 声明示例

"tools": [ { "name": "read_file", "description": "Read contents of a file" } ], "prompts": [ { "name": "code_review", "description": "Review code for best practices", "arguments": ["file_path"], "text": "Review this code: ${arguments.file_path}" } ]

🛡 安全与企业管理

Extensions 引入了新的安全考量，特别是对于企业环境。Anthropic 在预览版中内置了多层安全措施。

👤 用户安全

  • 敏感数据存储在 OS Keychain 中
  • 扩展自动更新，及时修补漏洞
  • 可以审计已安装的扩展列表
  • 安装前可查看权限和能力声明

🏢 企业管控

  • Group Policy (Windows) + MDM (macOS) 支持
  • 预安装已审批的扩展到员工设备
  • Blocklist 指定扩展或发布者
  • 完全禁用扩展目录功能
  • 部署私有扩展目录

📋 Extension Directory 提交审核

Claude Desktop 内置了一个策展的扩展目录。用户可以浏览、搜索并一键安装。开发者提交扩展的流程：

遵循提交指南
确保扩展符合官方提交表单中的所有指南要求。
跨平台测试
在 Windows 和 macOS 上充分测试扩展的功能和稳定性。
提交审核
通过官方表单提交扩展，Anthropic 团队会进行质量和安全审查。
