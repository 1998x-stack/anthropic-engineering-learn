⚖️ LLM Judge 评判

真实网站无法确定性评判。使用 gemini-2.5-flash 作为 LLM Judge，二元判定比 rubric 评分更可靠。

❌ Rubric 评分

听起来更好

实际：成功和失败都给中间分

不可靠的灰度判定

✅ Binary Verdict

简单 true/false

人类标注 200 traces 对齐
