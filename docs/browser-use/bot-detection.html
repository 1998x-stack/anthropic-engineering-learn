🐱 Cat & Mouse 博弈即将升级

Antibot 系统能检测到的远比它们实际阻止的多。它们保守是因为 false positives 会损害转化率。但 AI agent 流量的暴增将改变这个平衡。

现状：保守阈值
Antibot 系统（Akamai, Cloudflare, DataDome）保守设置阈值 — false positives 的代价太高。大多数自动化仍然有效。
临界点：Bot 流量暴增
AI agents 即将大规模涌入。当 bot 流量达到临界点，放行 bot 的成本将超过误封人类的成本。
结果：收紧检测
JS patches, stealth plugins, CDP hacks — 已经可被检测。只是 antibots 还没拉闸。
我们的方案
不依赖 antibot 的宽容，而是做到真的没有什么可检测的。
