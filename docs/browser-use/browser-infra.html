⚡ 极简接入：One API Key

与本地使用完全相同的代码，只需加一行 use_cloud=True。

from browser_use import Agent, Browser, ChatOpenAI # Use Browser-Use cloud browser service browser = Browser( use_cloud=True, # Automatically provisions a cloud browser ) agent = Agent( task="Your task here", llm=ChatOpenAI(model='gpt-4.1-mini'), browser=browser, )
设置 API Key
→
use_cloud=True
→
自动 provision 云浏览器
→
规模化运行 Agent
