⚙️ 工作原理

Pre-baked AMI，30-60 秒启动。locked-down IAM role，零 AWS 权限。Context 跨消息持久化。

Pre-baked AMI
→
30-60s Spin-up
→
Claude Code Session
→
Telegram Bot

🔒 安全

VM 运行在 locked-down IAM role 下，零 AWS 权限。无法触及你的基础设施或 Browser Use 的。

💾 持久化

Telegram 连接一个 resumed Claude Code session，context 跨消息持久。Browser sessions 每 240 分钟轮换。

开源架构

完整架构开源，可自托管。Web terminal 直接浏览器访问，SSH 本地访问。

🛠️ Setup：5 分钟内完成

三步完成：启动 VM、登录 Claude Code、创建 Telegram Bot。

Step 1: 启动 VM
访问 cloud.browser-use.com/bux，启动你的 VM
Step 2: 登录 Claude Code
在 web terminal 中登录 Claude Code
Step 3: Telegram Bot
通过 @BotFather 创建 bot，粘贴 token。Token 保存在你的 box 中。

🔑 给 BUX 访问权限

BUX 的能力取决于它能访问的账户。使用 Browser Use Profiles 同步 cookies 或手动构建。
