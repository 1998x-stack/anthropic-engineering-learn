🌎 Agent 电商时代

AI agent 已经在大规模地浏览网页 —— 搜索、比较产品、代替用户做购买决策。New Generation 正在构建工具帮助品牌为这个趋势做好准备。

Agent 购物流程

🤖 用户下达购物指令
→
🔎 Agent 搜索产品
→
📊 比较价格/评价
→
🛒 完成购买

"AI agents are already browsing the web at scale -- searching, comparing products, and making purchase decisions on behalf of users." — Luka Secilmis

🔭 Kepler 平台

Kepler 是 New Generation 的 agentic commerce 平台，帮助品牌理解 AI agent 如何体验它们的网站，以及哪些环节会出问题。

🔎

Agent 体验审计

模拟 AI agent 访问品牌网站，发现 agent 无法完成的操作和断裂的用户旅程。

🎯

Agent Score

量化评估网站对 AI agent 的友好程度：导航能力、信息提取、推理支持。

📊

实际购物任务

使用真实电商 workflow 测试：搜索、筛选、加购、结账等完整流程。

📈 Agent Score 评估维度

Agent Score 从三个核心维度评估网站的 agent 就绪度，帮助品牌识别优化方向。

Agent Score 评估维度权重
Access — 信息可访问性
Agent 能否访问产品信息
Navigate — 导航能力
Agent 能否完成购物流程
Reason — 推理支持
信息是否支持 Agent 推理决策

✅ Agent-Ready 网站

  • 结构化产品数据
  • 清晰的 DOM 层级
  • 可预测的导航流程
  • 无过度依赖 JS 渲染

❌ Agent-Hostile 网站

  • 动态加载无语义标记
  • 复杂 anti-bot 机制
  • 需登录才能查看基本信息
  • 过度使用 iframe / shadow DOM

⚡ Browser Use 赋能

New Generation 使用 Browser Use 启动数百个并发浏览器会话，对真实品牌网站进行 agent 就绪度测试。自 2 月以来已执行超过 12 万个 BU 任务。
