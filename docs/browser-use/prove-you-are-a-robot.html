❌ 传统 CAPTCHA

  • 设计目的：阻止机器人
  • 让人类证明自己是人类
  • 识别图片、点击方块
  • 对 agent 不友好

✅ 反向 CAPTCHA

  • 设计目的：阻止人类
  • 让 agent 证明自己是 agent
  • 解析混淆文字 + 数学计算
  • Agent 一次 forward pass 搞定

🔬 反向 CAPTCHA 原理

随机生成问题类型、参数和语言，将数字拼写为该语言的文字，然后进行混淆：大小写交替、注入随机符号、打乱空格。

💡 语言彩蛋

挑战中 luka 指的不是作者 Luka 的名字，而是 Toki Pona 语言中 "五" 的意思。系统会从多种语言中随机选择数字拼写方式，增加混淆难度。
