🎯 构建方法论

Flo 认为 AI agent 需要两半：正确的工具集合 + 知道如何使用它们。

"We think of our approach as two halves. An AI agent needs: the correct collection of tools, and to know how to utilize them."

核心聚焦

Lindy 团队专注于第二点 — 让 agent 通过自我经验学习如何更好地使用工具。集成不是核心风险，认知能力才是。

🔧 自研工具链

Lindy 全部 agent 工具都是内部自研，核心是"比 Langsmith 好得多"的 tracer。

Tracer
逐步展示 agent 决策过程
Memory
查看/编辑 agent 学到的经验
Tool Review
查看/编辑工具使用规则
Benchmarks
持续监控 agent 表现

🔒 可靠性与挑战

高风险操作时 agent 请求用户确认，随着学习用户偏好，确认频率逐渐降低。

认知架构

"Coming up with the right cognitive architecture is insanely challenging — but we wouldn't outsource it, since we believe that's our purpose."

Fine-tuning 挑战

需要 40B+ 参数和 8k+ context window 的大模型，部署推理规模化是另一个重大挑战
