🎯 产品架构

Cognosys 是 web 版 AutoGPT/babyAGI，以"循环"方式工作 — 分解高层任务、调用 LLM、迭代至完成。

"The people that have found value within first experience with the agents are the ones who become returning users." — Sully Omar

核心使用场景

互联网研究 Agent 最受欢迎 — 类似 Perplexity AI，接受目标、执行研究、综合信息、提供来源链接。

🔥 五大挑战

从部署到延迟，Agent 产品面临的核心工程挑战。

部署：Serverless 困境
Vercel 60 秒超时→Cloud Functions 不理想→最终选择 Cloud Run 统一 API
可观测性
多因素影响成功/失败，使用 Sentry + Google Cloud + Langsmith 组合
测试与评估
如何定义"好的输出"？简单任务可二元判断，复杂任务（写作/研究）评估极困难
调试
自研 agent 步骤重试系统，失败时通知用户重新运行
延迟
传统 SW 200ms 即慢，Agent LLM 调用 30 秒+，运行 60 秒到 5 分钟
传统 SW 标准
200ms
单次 LLM 调用
30+ 秒
Agent 完整运行
60 秒 - 5 分钟

🔮 未来方向

专注少数高价值场景，避免让 agent 做所有事。

"It's very easy to want to do everything with the agent, but with the current models, it is impossible to do all these things well. And once the users get frustrated, they leave and never return." — Sully Omar
