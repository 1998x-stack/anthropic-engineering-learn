🎯 2024 预测

开发者普遍认为 2024 是 AI agent 之年 — 更多整合、更低门槛、更实际的结果。

Ismail (Superagent)

LLM extensions/adapters 将大量涌现 — 类似数据库扩展，增强 LLM 能力而不依赖 prompt 技巧

Ted (Rubric Labs)

Agent 将在 2024 展现实际成果。低代码工具和教育降低进入门槛

Jonathan (Fine)

Kaveen (OpenAI)

Brendon (Athena)
