🤖 什么是 AI Agent

Agent 使用短期记忆（in-context learning）和长期记忆（vector store），具备规划、逐步思考和自我反思能力，并能使用工具。

短期记忆

In-context learning — 利用对话上下文理解任务

长期记忆

外部 vector store 检索历史信息

规划能力

将目标分解为小任务，逐步执行

工具使用

网页抓取、日历操作、终端命令等
