🌱 新生态形成

LLM 被比作新的 kernel 进程（Andrej Karpathy），围绕 Agent 的前后端、记忆管理、构建框架和 SDK 正在快速成熟。

生态组合示例

AgentLabs (AI 前端) + E2B (安全 Sandbox) + GPT-4 (模型) = 完整 Agent 应用

AI Engineer 需求

数百至数千人已自称 AI Engineer，但百万级需求缺口仍然巨大

🔒 安全与隐私

让 LLM 产生的 untrusted code 在用户操作系统上运行，后果难以预料。

不安全方式

Open Interpreter 直接操控终端 — GPT 的 pip install 曾破坏其自身依赖

安全方式

E2B 沙箱云环境 / Kubernetes 沙箱节点 — 严格限制出站调用和数据访问

"The challenge is having the right mix between deterministic and non-deterministic routines. More mission-critical tasks require more determinism." — Jose Maria Lago, GenWorlds

🧠 RAG 与记忆

RAG 是 Agent 记忆的核心方案，但存在权限、上下文窗口和数据源问题。

🔄 测试 & 多 Agent

GAN-like 架构可能是测试 AI 代码的答案；多 Agent 通信正成为主要议题。

测试方法

Codium CPO 提出 GAN-like 架构 — 一个生成、一个批评，弥补行业对代码覆盖率指标的过度依赖

Self-healing 争议

Google DeepMind 论文显示 LLM 无法通过自我反思真正改进；但 AutoGen 的实际用例似乎证明 agent 间调试有效

🎯 结论

Agent 有潜力成为 LLM 应用架构的核心，但离生产就绪还有距离。

"I think the only successful agents are the ones that do really small things. So very specific, small things like fix the color of this button on the website." — Kanjun Qiu, CEO Imbue

已验证有效

编码 agent（数据可视化、代码辅助）已经展现实用价值。Agent 正在从独立存在转向成为复杂产品的内嵌组件。
