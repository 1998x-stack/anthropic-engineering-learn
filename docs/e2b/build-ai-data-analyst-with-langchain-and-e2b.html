🔒 为什么选择 E2B 云端沙箱

相比本地 Docker 执行，E2B Data Analysis Sandbox 提供远程安全代码执行环境，防止 LLM 生成的不可预测代码对本地机器造成危害。

本地执行风险

LLM 生成的代码可能访问敏感数据、修改系统文件、执行恶意操作

E2B 沙箱方案

远程隔离环境；安全执行未知代码；支持动态安装包；支持图表生成与文件操作
