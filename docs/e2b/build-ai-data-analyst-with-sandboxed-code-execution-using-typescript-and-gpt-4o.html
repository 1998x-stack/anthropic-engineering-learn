🚀 Code Interpreter SDK

E2B 开源的 Code Interpreter SDK 基于 Firecracker 微虚拟机创建安全云端沙箱，内置 Jupyter 服务器供 LLM 使用。

核心能力

自定义包安装网络访问文件系统云存储连接

模型无关

兼容任何 LLM。本例使用 GPT-4o 展示多模态能力 —— 生成图表后"看"图表并分析。

⚙️ 环境配置

npm 初始化 + 依赖安装 + API Key 配置。

npm init -y && npm i @e2b/code-interpreter dotenv openai

关键依赖

@e2b/code-interpreter（代码执行）、openai（LLM 调用）、dotenv（环境变量管理）

🛠️ 工具定义

定义 execute_python 工具，让 GPT-4o 可以在 E2B 沙箱中执行 Python 代码。

System Prompt 定义角色
→
execute_python 工具
→
Function Calling 规范

System Prompt 设计

角色定义为 Python 数据科学家；每次调用执行独立 cell；支持 matplotlib 直接展示；可安装 pip 包；完全安全的沙箱环境。

🔧 代码执行器实现

codeInterpret 函数通过 notebook.execCell 在 E2B 沙箱中执行代码，支持 stdout/stderr 流式输出。

execCell 执行代码
在 Jupyter 沙箱中执行 Python 代码，支持 onStderr/onStdout 回调
错误处理
exec.error 检查执行错误并抛出异常
结果返回
返回 exec.results 包含图表、数据等多种格式

👁️ GPT-4o 多模态交互

GPT-4o 的独特能力：生成图表 → 以 base64 图片形式"看"图表 → 分析并生成新图表。

第一轮：生成

"写一个二阶微分方程并绘制解的图表"

第二轮：分析 + 重新生成

"根据你看到的图，判断微分方程，然后用不同初始条件重新绘制"

这展示了 GPT-4o 的视觉理解能力 —— 不仅能生成代码和图表，还能"看"自己生成的输出并做出反应。

📊 运行结果

程序生成两张 PNG 图片：原始微分方程解和不同初始条件下的解。

输出文件

image_1.png（原始方程解）和 image_2.png（修改初始条件后的解），自动保存到项目目录。执行完毕后调用 codeInterpreter.close() 释放资源。
