🚀 Code Interpreter SDK

E2B 的开源 Code Interpreter SDK 基于 Firecracker 微虚拟机，提供运行中的 Jupyter 服务器，支持自定义包安装、网络访问和文件系统操作。

📦 依赖安装

安装 E2B Code Interpreter SDK 和 LangChain Python SDK。

pip install e2b-code-interpreter langchain langchainhub langchain-openai

🔧 代码解释器实现

CodeInterpreterFunctionTool 类封装了 E2B SDK，提供 Pydantic 输入验证和 LangChain 工具格式转换。

Pydantic 输入验证
LangchainCodeInterpreterToolInput 确保输入为合法 Python 代码字符串
长期沙箱实例
构造函数创建持久化 CodeInterpreter 实例，持续 ping E2B 云保活
结果过滤
过滤掉 results key（含图片/plots 等大数据），避免占用 LLM 上下文窗口
ToolMessage 格式化
将执行结果转换为 LangChain ToolMessage 格式返回

🤖 Agent 构建

使用 RunnablePassthrough + ChatPromptTemplate + bind_tools 构建 Agent 管道。

Agent 管道架构

RunnablePassthrough（格式化中间步骤）→ ChatPromptTemplate（用户输入）→ llm.bind_tools（绑定工具）→ ToolsAgentOutputParser（解析输出）

📊 执行与结果

给 Agent 下达"绘制正弦波"的任务，Agent 自动生成 matplotlib 代码并在 E2B 沙箱中执行。

输出结果

Agent 成功调用 code_interpreter 工具，生成 numpy + matplotlib 代码，在 E2B 沙箱中执行并返回正弦波图表。中间步骤可通过 result["intermediate_steps"] 查看。

使用完毕后调用 code_interpreter.close() 关闭沙箱环境。
