🔒 E2B Sandbox 执行层

每个集成 Maige 的仓库都获得独立的 E2B 沙箱实例 —— Agent 的专属开发者工作空间。

1. 仓库克隆
将用户仓库克隆到 E2B 沙箱环境中
2. 依赖安装
在隔离环境中安装项目依赖
3. Shell 命令执行
Agent 像初级开发者一样运行 shell 命令
4. 测试与调试
运行测试、复现 issue 或错误
5. 代码提交
编写代码、commit、以 bot 身份开 PR

🌐 开源战略

开源不仅是个人偏好，更是在 AI 时代软件商品化趋势下的战略选择。

去中心化维护

项目不依赖单一团队，社区可以共同维护和演进

软件商品化趋势

AI 降低开发成本 → 专有软件护城河越来越难建 → 开源符合趋势

网络效应

开源客户的用例天然公开 → 形成产品网络效应 → 降低获客成本

竞争格局

同领域有 Sweep.devDosu.devCodegen 等玩家。Ted 认为"空间足够大"，关键是帮助小团队围绕商业开源公司构建社区。

⚡ 挑战与未来展望

AI Agent 的非确定性和代码生成能力是核心技术挑战。

当前挑战

生成式 AI 写代码不够好；修改/插入代码更难；Agent 可能陷入循环或放弃任务

未来方向

基于视觉的 AI 前端开发；识别 a11y 问题和 UI bug；改进代码搜索（embedding + 向量数据库）

"如果开源模型能达到 GPT-3.5 水平但便宜 10-100 倍，Agent 可以更具探索性，做出更多有趣的事。这是我真正兴奋的方向。"
