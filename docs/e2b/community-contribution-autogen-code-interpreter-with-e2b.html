🚀 项目概述

社区贡献者 Keegan McCallum（Xler.ai 创始人）构建了一个开源 cookbook 示例，展示如何将 AutoGen agents 与 E2B sandbox 集成用于代码解释执行。

项目核心

这个项目将 LLM 生成的代码从本地 Docker 执行迁移到 E2B 云端沙箱执行。AutoGen 默认通过本地 Docker 执行代码，但这在安全性和可扩展性上存在局限。E2B sandbox 提供了安全的云端替代方案。

Xler.ai 平台

Xler 是一个建立在 AutoGen 之上的通用多 Agent 平台，提供 evaluation、deployment、monitoring 和 fine-tuning 等生产级服务。

🔒 E2B Sandbox 核心

E2B Sandbox 是一种安全运行 AI 应用的长时间运行云环境，支持任何 LLM 使用 tools，完全开源。

关键特性

支持 GPT、Claude、本地 LLM 等所有模型；基于 Firecracker microVM 的隔离环境；完全开源（包含基础设施层）；可自由安装自定义包、访问互联网和文件系统。

⚖️ 对比：本地 vs 云端执行

为什么 E2B 云端执行优于 AutoGen 默认的本地 Docker 执行。

❌ 本地 Docker 执行

安全隔离不完善、资源受限于本地机器、难以支持多用户并发、生产环境部署困难、依赖冲突风险高

✅ E2B 云端 Sandbox

Firecracker microVM 完全隔离、弹性云资源、天然支持多租户、生产就绪、独立环境无冲突
