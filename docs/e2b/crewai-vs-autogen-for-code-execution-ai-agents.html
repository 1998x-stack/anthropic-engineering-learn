📈 多 Agent 框架的崛起

"More Agents Is All You Need" 论文发现 LLM 性能随 Agent 数量扩展。CrewAI 被称为 "AutoGen 2.0"。

AutoGen (Microsoft)
成熟度高
CrewAI
快速增长

CrewAI 特色

基于 LangChain 构建；Agent 可以互相委托工作；快速上手 + 丰富用例（股票分析、Instagram 帖子、旅行规划、Landing Page 生成）

🔧 AutoGen：执行能力强

AutoGen 通过 Docker 容器执行 LLM 生成的代码，能生成图表并保存到本地。

执行流程

Agent 生成代码 → Docker 容器执行 → 结果（如 PDF 图表）保存到用户电脑。支持 GPTAssistantAgent 实验性功能。

Docker 执行E2B 云端替代

📝 CrewAI：默认文本输出

CrewAI 默认生成文本报告，需要额外集成 LangChain 工具才能执行代码。

CrewAI 限制

默认无代码执行能力；搜索工具好用但复杂分析需要代码执行工具

可选的 LangChain 工具

Pandas Dataframe、Python REPL、Bearly Code Interpreter —— 但各有安全警告

⚠️ 安全性限制

LangChain 官方工具明确警告：运行 LLM 生成的代码可能有害。

"This can be bad if the LLM generated Python code is harmful. Use cautiously." —— LangChain Pandas Dataframe 官方文档

安全解决方案

E2B 提供云端隔离沙箱，可作为 AutoGen 和 CrewAI 的安全代码执行层。社区也在呼吁 LangChain 增加更安全的代码执行方式。

💡 核心结论

两个框架各有优势，选择取决于具体需求。

选 AutoGen

需要代码执行能力；需要更多自定义控制；已有 Docker 基础设施

选 CrewAI

已熟悉 LangChain；需要快速上手；Agent 角色委托场景
