🎯 功能概述

E2B 新增对 sandbox 计算资源的自定义能力，开发者可以根据工作负载灵活调整 CPU 和 RAM。

为什么需要自定义计算资源

不同 AI 任务对计算资源的需求差异巨大：轻量级代码执行可能只需 1 核 CPU，而数据分析或模型推理可能需要多核 CPU 和大量内存。E2B 允许在构建 custom sandbox template 时指定精确的计算规格。

🔧 配置步骤

通过 E2B CLI 构建自定义 sandbox template，指定 CPU 和内存参数。

安装 E2B CLI
→
e2b template build
→
指定 CPU & RAM
→
部署使用
$ e2b template build --cpu-count 4 --memory-mb 8192

📋 CLI 命令详解

E2B CLI 的 template build 命令支持的关键参数。

--cpu-count
指定 CPU 核心数
--memory-mb
指定内存大小 (MB)
template build
构建自定义模板

💡 使用场景

不同 AI 工作负载的推荐配置。

轻量级任务

简单代码执行、文本处理 — 1-2 CPU，512MB-1GB RAM 即可满足

重型计算任务

数据分析、模型推理、大规模并发 — 4+ CPU，8GB+ RAM 提供充足资源
