🎉 官方集成

E2B 成为 OpenAI Agents SDK 的沙箱提供商。几行代码即可为 Agent 提供自定义环境、资源隔离和安全边界。

Agents built with the OpenAI Agents SDK will get their own sandboxes featuring custom environment with resource isolation, security boundaries, and persistence.

文件编辑、Shell 命令、工作空间持久化、实时预览、并行沙箱。

🎬 Demo：Landing Page 生成

完整工作流展示 —— 从沙箱创建到并行生成多个 Landing Page 变体。

1. 创建沙箱 Session
用 E2B SDK 定义 builder agent 并赋予文件编辑能力
2. 从零生成页面
Agent 编写 HTML/CSS，部署到沙箱并通过 preview URL 预览
3. Diff 迭代
应用补丁而非重写全部，加速迭代周期
4. 并行变体生成
同时启动多个沙箱，每个运行独立 Agent，并行生成多个设计方案
