🌟 Codestral 简介

Mistral AI 发布的 open-weight 代码生成模型，在长距离代码生成评估中超越其他模型，精通 80+ 编程语言。

代码生成能力

关键限制

Codestral 暂不支持 tool/function calling，因此需要通过指令让模型返回 Markdown 格式的 Python 代码块，然后在客户端解析提取代码。

🔧 Code Interpreter SDK

E2B 的 Code Interpreter SDK 快速创建基于 Firecracker 的安全云沙箱，内置 Jupyter server。

Code Interpreter SDK 支持自定义包安装、互联网访问、文件系统操作、云存储连接，兼容任何 LLM。

📝 实现步骤

6 步构建完整的 Codestral + E2B 数据分析 Agent。

Step 1: 安装依赖
pip install mistralai e2b_code_interpreter
Step 2: 定义 API Keys & Prompt
配置 Mistral/E2B API key，编写 system prompt 指令模型返回 Python 代码块
Step 3: Code Interpreter 方法
使用 e2b_code_interpreter.notebook.exec_cell() 在沙箱中执行代码
Step 4: Chat 方法
调用 Codestral LLM，解析输出提取 Python 代码块，调用 code_interpret
Step 5: 数据上传
将 CSV 数据集上传到 E2B sandbox 的文件系统
Step 6: 整合运行
使用 CodeInterpreter context manager 实例化并执行完整数据分析流程

💻 代码解析

关键代码模式：Markdown 解析替代 function calling。

import re
pattern = re.compile(r'```python\n(.*?)\n```', re.DOTALL)

def match_code_block(llm_response):
  match = pattern.search(llm_response)
  if match:
    return match.group(1)
  return ""

设计思路

System prompt 指示模型始终以 Markdown 格式返回 Python 代码块，客户端使用正则表达式提取代码，作为不支持 function calling 的有效替代方案。
