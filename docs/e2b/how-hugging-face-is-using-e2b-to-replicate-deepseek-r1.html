🎯 Open R1 背景

DeepSeek-R1 发布后，Hugging Face 启动 Open R1 项目，逆向工程缺失的数据和训练 pipeline。

核心方法：RLVR

Reinforcement Learning with Verifiable Rewards — LLM 训练解决可验证正确性的问题，根据答案正确与否获得 1 或 0 的二元奖励。数学题用 Math-Verify 解析字符串验证，编程题则需要实际执行代码。

⚙️ RLVR 训练流程

竞赛编程的奖励需要执行 LLM 生成的代码并与 test cases 对比结果。

"本地执行 LLM 生成的代码风险极高 — 模型可能生成损坏硬盘甚至 rm -rf 整个目录的程序。" — Hugging Face 文档

🔧 集成实现

几小时即可完成 E2B 集成，使用异步 Sandbox 并发启动数百个实例。

异步并发

AsyncSandbox.create() + asyncio.gather() 并发运行数百个脚本

Sandbox 持久性

跨调用保持状态，Jupyter-like notebook 执行模式

多语言支持

指定语言参数即可切换 Python/JS/C++/Rust/Lean4

快速集成
