🏗️ 架构概览

E2B Code Interpreter SDK 通过 Firecracker microVM 提供安全的云端 Jupyter 执行环境，让 Llama 3 生成并运行代码。

❌ 传统方式

本地执行 LLM 生成的代码，存在安全风险，缺乏隔离性，难以扩展到生产环境

✅ E2B 方式

在 Firecracker 安全沙箱中运行代码，完全隔离，支持互联网访问和文件系统操作

⚙️ 环境配置

安装 Groq SDK 和 E2B Code Interpreter SDK，配置 API Keys 和系统提示词。

🔧 Code Interpreter 实现

定义核心函数 code_interpret()，通过 E2B SDK 在云端 Jupyter 中执行代码。

核心执行函数

def code_interpret(e2b_code_interpreter, code): exec = e2b_code_interpreter.notebook.exec_cell( code, on_stderr=lambda stderr: print("[stderr]", stderr), on_stdout=lambda stdout: print("[stdout]", stdout), ) if exec.error: print("[ERROR]", exec.error) else: return exec.results

📤 输出支持

支持 stdout/stderr 流式输出，可获取图片（PNG/JPG/PDF）、文本等多种结果格式

🔒 安全沙箱

每次执行都在隔离的 Firecracker microVM 中进行，不影响主系统安全

🤖 Llama 3 调用

通过 Groq API 调用 Llama 3，使用 Function Calling 机制触发代码执行。

1. 构建消息
将 system prompt 和用户消息发送给 Groq API
2. 模型推理
Llama 3 分析请求，决定是否调用 execute_python 工具
3. 解析 Tool Call
从响应中提取 function_name 和 function_args（code 参数）
4. 执行代码
调用 code_interpret() 在 E2B 沙箱中运行代码
5. 返回结果
将执行结果（图表、数据）返回给用户
