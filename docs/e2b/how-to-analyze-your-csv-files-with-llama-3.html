📤 文件上传机制

CSV 文件通过编程方式（而非 AI 生成的代码）上传到 E2B 沙箱文件系统。

上传代码

def upload_dataset(code_interpreter): with open("./city_temperature.csv", "rb") as f: remote_path = code_interpreter.upload_file(f) print("Uploaded at", remote_path) # → /home/user/city_temperature.csv

AI 生成下载代码

让 LLM 生成 URL 下载代码不可靠，可能幻觉虚假 URL

编程方式上传

直接上传本地文件到沙箱，路径确定，AI 仅负责分析

🚀 完整流程

从安装依赖到生成温度分布图表的六步流程。

1. 安装依赖
pip install groq e2b_code_interpreter
2. 配置 API Key + Prompt
Groq + E2B Key，定义数据科学家角色和 CSV schema
3. Code Interpreter 函数
code_interpret() 通过 exec_cell 执行代码
4. LLM 调用与工具解析
chat_with_llama() 处理 Function Calling 流程
5. 上传数据集
upload_dataset() 将 CSV 传入沙箱
6. 运行分析
"Plot average temperature over the years in Algeria"
