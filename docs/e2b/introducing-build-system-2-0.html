🎯 为何重建

旧构建系统需要在 config 文件、Dockerfile 和 CLI 命令之间来回切换，构建缓慢且调试痛苦。

旧系统

e2b template build + config + Dockerfile；构建慢、多为本地；调试困难；无法暴露给用户

新系统 2.0

纯代码定义 → 自动构建；智能缓存 + 并行上传；AI IDE 可解析/生成

📊 Before vs After

代码示例对比：从 config + Dockerfile 到纯链式 API。

// JavaScript
Template()
  .fromImage("node:24")
  .copy("src/", ".")
  .runCmd("npm install")

# Python
Template()
  .from_image("python:3.11")
  .pip_install(["requests", "numpy"])
  .copy("app.py", ".")
  .run_cmd("python app.py")
