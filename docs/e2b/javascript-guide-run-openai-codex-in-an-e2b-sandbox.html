OpenAI Codex 将自然语言指令转为代码编辑，E2B Sandbox 提供隔离的长时间运行环境，Agent 可安全地创建文件、安装工具和执行代码。

🔧 E2B JS SDK

创建和控制 Sandbox 的核心库，管理沙箱生命周期（创建→执行→关闭）

📦 预构建模板

openai-codex 模板已预装 Codex CLI，无需额外安装即可直接运行

🔑 dotenv

从 .env 文件加载 E2B_API_KEY，安全管理密钥配置

🛡️ 安全执行

使用 --dangerously-bypass-approvals-and-sandbox 标志在沙箱内自动执行

📁 项目初始化

创建项目结构，配置 package.json 和环境变量文件。

项目结构

openai-codex-in-sandbox-js/ ├─ src/ │ └─ index.ts ← 主程序 ├─ package.json ├─ .gitignore ← 先于 .env 提交 └─ .env ← E2B_API_KEY
Step 1: 创建目录
mkdir openai-codex-in-sandbox-js && cd && mkdir -p src
Step 2: 配置 .gitignore
确保 .env 和 node_modules/ 不被提交
Step 3: 设置 API Key
在 .env 中配置 E2B_API_KEY
Step 4: npm install
安装 e2b、dotenv、tsx 依赖

💻 核心代码实现

src/index.ts 完成四个核心操作：加载配置→创建沙箱→执行 Codex→清理资源。

创建沙箱并注入 OpenAI Key

import { Sandbox } from 'e2b' import dotenv from 'dotenv' dotenv.config() const sbx = await Sandbox.create('openai-codex', { envs: { OPENAI_API_KEY: '<your api key>' }, }) console.log('Sandbox created', sbx.sandboxId)

运行 Codex Prompt

const result = await sbx.commands.run( `codex exec --skip-git-repo-check \\ --dangerously-bypass-approvals-and-sandbox \\ "Create a hello world index.html"`, { timeoutMs: 0 } ) console.log(result.stdout) sbx.kill()

Sandbox 生命周期

创建 (create)
~150ms
执行 (run)
根据任务复杂度
清理 (kill)
即时

🚀 运行与结果

npm run start 执行后，Codex 在沙箱文件系统中生成 index.html，控制台输出执行结果。

❌ 本地直接运行

安全风险高，需手动管理依赖，无法轻松清理生成文件

✅ E2B Sandbox 运行

完全隔离，文件仅存在于沙箱内，执行完毕自动清理

"生成的 index.html 存在于沙箱文件系统内。Sandbox 关闭后，所有临时文件自动清理。"
