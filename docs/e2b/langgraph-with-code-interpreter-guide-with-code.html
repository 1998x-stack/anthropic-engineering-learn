🏗️ 整体架构

LangGraph 的 MessageGraph 管理 Agent 和 Action 节点之间的状态流转，E2B 提供安全的 Jupyter 代码执行环境。

Human Message
→
Agent (LLM + Tools)
→
Action (Code Execute)
→
Agent (检查结果)
→
END

❌ 无条件循环

简单链式调用无法根据 LLM 决策动态选择路径，缺乏自主性

✅ 条件路由

LangGraph 的 conditional_edges 让 Agent 自主决定是调用工具还是结束任务

🔄 LangGraph 工作流

使用 MessageGraph 构建 Agent→Action 的条件循环工作流。

定义 should_continue
检查最后一条消息是否包含 tool_calls，决定走向 "action" 还是 END
定义 execute_tools
遍历 tool_calls，通过 tool_map 分发到对应的 Tool handler
构建 Graph
添加 agent 节点（LLM）和 action 节点（工具执行），设置条件边
编译 & 调用
workflow.compile() 后 app.invoke() 传入用户消息
清理资源
调用 code_interpreter.close() 关闭 E2B Sandbox
workflow = MessageGraph() workflow.add_node("agent", llm.bind_tools(tools)) workflow.add_node("action", lambda x: execute_tools(x, tool_map)) workflow.add_conditional_edges("agent", should_continue) workflow.add_edge("action", "agent") workflow.set_entry_point("agent") app = workflow.compile() result = app.invoke([("human", "plot and show sinus")])

🚀 运行结果

Agent 接收 "plot and show sinus" 指令，自动生成 matplotlib 代码并在 E2B 沙箱中执行，返回正弦波图表。

import matplotlib.pyplot as plt import numpy as np x = np.linspace(0, 2*np.pi, 100) y = np.sin(x) plt.plot(x, y) plt.title('Sine Wave') plt.grid(True) plt.show()
