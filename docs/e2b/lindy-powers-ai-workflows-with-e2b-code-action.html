🔗 从 No-Code 到 Code

Lindy 的可视化工作流构建器在用户需要高级数据操作、自定义 API 集成和复杂条件逻辑时遇到了瓶颈。

"在集成 E2B 之前，我们的用户不断地碰到纯视觉工作流的极限。他们需要以特定方式操作数据、连接小众 API 或实现复杂的条件逻辑。" -- Luiz Scheidegger, Lindy 工程负责人

📊 高级数据操作
