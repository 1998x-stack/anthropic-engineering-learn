🔄 两种代码生成方式

Llama 3.1 支持内置 Function Calling 和手动 Markdown 解析两种方式，本指南使用更通用的第二种。

内置 Function Calling

原生支持，定义 JSON 格式的 tools，LLM 决定调用。但大段代码生成时经常提前截断。

Markdown 手动解析

指示 LLM 在 ```python 代码块中返回代码，手动正则提取。更通用，适用任何 LLM。

"虽然 Llama 3.1 支持 Tool Calling，但在生成较大代码片段时经常在完成前截断。这促使我使用第二种方式。"
