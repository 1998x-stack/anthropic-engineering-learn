🔄 两种方式对比

Function Calling vs Markdown 手动解析——本教程选择后者以获得更通用的方案。

Function Calling

原生 JSON 定义工具，LLM 自动调用。推荐 70B/405B，但大段代码易截断。Llama 内置 Brave Search、Wolfram Alpha、Code Interpreter。

Markdown 解析

System Prompt 中要求返回 ```python 代码块，用 re.compile 正则提取。更通用，适用任何 LLM，不依赖 provider 的 Function Calling 支持。

💻 Python 实现

核心三函数：code_interpret()、match_code_blocks()、chat_with_llm()。

正则提取代码块

pattern = re.compile( r"```python\n(.*?)\n```", re.DOTALL ) def match_code_blocks(llm_response): match = pattern.search(llm_response) if match: return match.group(1) return ""
