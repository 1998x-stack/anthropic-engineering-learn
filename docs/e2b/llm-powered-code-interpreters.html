📚 传统 vs LLM 解释器

传统 code interpreter 将高级编程语言翻译为机器语言执行。LLM 时代增加了"AI 翻译"这一中间层。

⚡ 核心：代码执行能力

LLM Code Interpreter 的关键特征是能够执行代码，而非仅仅生成代码片段等待用户复制粘贴。

创建文件
在指定路径生成新文件
下载文件
自动下载外部资源
生成图表
基于数据可视化输出
运算结果
执行并返回计算结果

🌟 代表性产品

具备代码执行能力的 LLM-powered code interpreter 代表。

Open Interpreter

通过终端控制你的计算机，直接在本地执行 LLM 生成的代码

AutoGen Agents

Microsoft 的多 Agent 框架，可以执行代码进行数据可视化并保存文件

ChatGPT Code Interpreter

ChatGPT 的插件功能，具备代码执行能力（无插件时只能生成代码）

E2B Sandbox

开源的安全代码执行环境，支持在云端沙箱中运行 LLM 生成的代码

⚖️ 对比非执行工具

不具备代码执行能力的 AI 产品对比。

有 Code Interpreter

Open Interpreter、AutoGen、ChatGPT (with plugin) — 能够执行代码、修改文件系统、返回运算结果

无 Code Interpreter

ChatGPT (无插件)、Phind、Perplexity、GitHub Copilot — 只能生成代码文本，不能自动执行或改变系统
