🔒 代码执行与安全

AutoGen 默认通过本地 Docker 执行代码，但容器隔离并非完美。

本地 Docker 风险

Docker 默认 capabilities 和 mounts 可能提供不完整隔离；企业环境授权 AI 本地执行代码存在安全隐患

E2B 云端沙箱

安全的沙箱云环境，支持代码运行、进程启动、文件系统操作；天然支持多租户扩展

Self-healing code 示例：AssistantAgent 生成含错误的代码 → UserProxyAgent 反馈错误 → AssistantAgent 自动修复并重新生成。
