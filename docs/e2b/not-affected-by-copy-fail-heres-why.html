🔍 漏洞背景

algif_aead 内核模块的 2017 年优化让 page cache 页面落入可写的 scatterlist，配合 splice() 实现确定性 4 字节内核写入。

AF_ALG socket
→
splice() + AEAD
→
4 字节 page cache 写入
→
修改 /usr/bin/su
→
Root!

确定性攻击

不依赖竞态条件或时序，100% 可复现。只需非特权用户即可执行。

隐蔽性极高

腐蚀仅存在于内存中。磁盘取证显示原始文件——完全无痕迹。

🛡️ E2B 为何不受影响

E2B 为 Agent 沙箱构建自定义最小化内核——从未启用受影响的 CONFIG_CRYPTO_USER 模块。

内核配置

# CONFIG_CRYPTO_USER is not set # CONFIG_CRYPTO_USER_API_AEAD is not set

"更少的功能意味着更少的漏洞入口。安全和隔离在 99% 的日常中不会影响你。但那 1% 的影响超过其他 99% 的总和。这就是我们选择 VM 架构的原因。"

🔧 缓解措施

如果你无法立即补丁，至少禁用 algif_aead 模块并阻止 AF_ALG socket 创建。

临时缓解

echo "install algif_aead /bin/false" \ > /etc/modprobe.d/disable-algif.conf rmmod algif_aead 2>/dev/null || true

永久修复

补丁到 mainline commit a664bf3d603d。Ubuntu 26.04 (Resolute) 及以后版本不受影响。容器平台应在补丁后仍然用 seccomp 阻止 AF_ALG socket 创建。
