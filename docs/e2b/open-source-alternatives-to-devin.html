📊 SWE-bench 基准

2,294 个基于真实 GitHub Issues 和 PRs 的编码任务，评估模型解决实际问题的能力。

关键指标

模型需要理解真实代码库中的问题，在数千行代码中定位 bug，生成可与多个代码模块交互的解决方案。最初最佳模型 Claude 2 仅解决 1.96% 的问题。

📈 SWE-bench 对比

各替代方案的性能对比和特色。

SWE-bench 局限

目前仅包含 Python 任务；对使用 Java/Go/Swift/TypeScript 的团队参考价值有限

AutoCodeRover 优势

Structure-aware code search（AST 解析）+ 统计故障定位，解决率远超通用模型

🤔 是否会取代工程师

Devin 的 demo 存在争议，多个视频质疑其真实能力。

"Devins" 还远没有达到取代工程师的水平。SWE-bench 仅覆盖 Python，demo 被质疑 overselling。但可以持续关注进展，开源社区的快速跟进让这个领域充满活力。
