🚀 GPT-4 Turbo

更长上下文、更低价格、更多控制——GPT-4 Turbo 六大核心升级。

01. 上下文长度 128K
约 300 页标准书籍，从 8K/32K 跃升到 128K tokens
02. 更多控制
JSON Mode 保证有效 JSON 输出，多函数并行调用，可复现输出（seed 参数）
03. 知识更新至 2023.4
内置 RAG 检索功能，支持外部文档和数据库集成
04. 新模态
DALL-E 3 + GPT-4 Vision + TTS 全部进入 API
05. 定制化
GPT-3.5 Fine-tuning 扩展到 16K 版本，GPT-4 Fine-tuning 实验计划
06. 更高速率限制
GPT-4 客户 tokens/min 翻倍，Copyright Shield 法律保护
