📁 项目设置

标准 Python 项目结构，使用 pyproject.toml 管理依赖。

项目结构

openai-codex-in-sandbox-python/ ├─ src/openai_codex_in_sandbox_python/ │ └─ main.py ├─ pyproject.toml ├─ .gitignore └─ .env
创建虚拟环境
python -m venv .venv && source .venv/bin/activate
安装依赖
pip install -e . (e2b + python-dotenv)
配置环境变量
.env 中设置 E2B_API_KEY
运行程序
python src/openai_codex_in_sandbox_python/main.py

💻 核心实现

main.py 完成沙箱创建、Codex 执行和资源清理三步操作。

完整代码

from dotenv import load_dotenv from e2b import Sandbox load_dotenv() sbx = Sandbox('openai-codex', envs={"OPENAI_API_KEY": "<your key>"}, timeout=60 * 5) result = sbx.commands.run( "codex exec --skip-git-repo-check " "--dangerously-bypass-approvals-and-sandbox " "'Create a hello world index.html'", timeout=0) print(result.stdout) sbx.kill()

JS 版本差异

使用 Sandbox.create() 异步方法，import from 'e2b'，需要 tsx 运行

Python 版本特点

使用 Sandbox() 同步构造函数，from e2b import Sandbox，原生 Python 运行

🚀 运行验证

执行后控制台输出 Codex 结果，index.html 存在于沙箱文件系统内。

"生成的 index.html 仅存在于沙箱文件系统中。执行完成后，sbx.kill() 清理所有资源。"
