🚀 GitWit 产品演进

从单 prompt 生成整个应用 → 到快速迭代的可视化编辑器，GitWit 的产品哲学是"AI 越快完成，人类越早介入"。

V1：全自动生成
一个 prompt 生成完整仓库，等待数分钟，人类无法介入
V2：可视化编辑器
实时预览 + ~100 行代码 / ~10 秒生成，比 Vercel V0 更快
V3：多文件重构
AI 自动拆分组件到多个文件，支持组件复用

"Agent 自主运行越久，人类能贡献自己技能的空间就越小。" — 因此转向快速迭代模式。

🧪 Sandbox 中的浏览器测试

LLM 的非确定性要求每个测试运行至少 10 次。需要在沙箱中构建 React 应用、在浏览器中运行并检查错误。

Console 运行时错误

📈 LLM 对比与开源

ReactEval 可以量化不同 LLM 的前端生成性能，帮助做出模型切换决策。

开源协作

ReactEval 已开源并与其他公司合作。只需修改几行代码即可适配不同产品。代码生成算法也在开源中，推动行业协作。
