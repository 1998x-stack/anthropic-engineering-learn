🎯 三大核心能力

复制 Cursor Agent Mode 的三个关键能力：生成完整项目、修复代码、运行终端命令。

生成项目

从 Prompt 创建完整可运行的项目（如 Next.js TodoList）

修复/重构

对现有代码库进行 Bug 修复或代码重构

运行命令

在终端中执行命令评估程序状态（如运行测试）

📝 Prompt 工程

使用 Anthropic 推荐的 CoT (Chain of Thoughts) 格式，结合 Goal + Return Format + Warnings。

Agent Prompt 结构

You are a coding agent help the user to achieve the described task. When running commands, keep in mind that the terminal is non-interactive, use the '-y' flag. Once completed, return: <task_summary> </task_summary> Think step-by-step before you start the task.

Context Pushing (RAG)

预定义步骤将上下文推送给 LLM，适合分类、翻译等任务

Context Pulling (Agent)

LLM 通过工具主动拉取上下文，决定何时完成任务，真正自主

🔧 工具设计最佳实践

不要直接映射 API，而是站在 LLM 的角度设计工具——"我在这种情况下需要什么？"

❌ 朴素方式

runCode("code") + terminal("cmd") → LLM 混淆使用场景，产生 echo 写文件和字符串转义错误的无限循环

✅ 最佳实践

createOrUpdateFiles + readFiles + terminal → 清晰的职责分离，LLM 知道何时用哪个工具

工具职责分配

createOrUpdateFiles
文件创建/更新（E2B FS API）
readFiles
文件读取（E2B FS API）
terminal
终端命令（E2B Commands）

"设计有用的 Agent 工具需要 'LLM 共情'——问自己在同样情况下需要什么工具。错误也要返回给 Agent，使其能够自我纠正。"

🔄 自主循环机制

AgentKit 的 Network 概念让 Agent 在循环中运行，直到生成 task_summary 或达到最大迭代次数。

Iteration 0-1
创建 Next.js 项目，安装测试依赖
Iteration 2-5
创建组件、测试文件、Jest 配置
Iteration 6-7
设置 npm scripts，更新页面入口
Iteration 8
运行 jest --coverage，100% Stmts/Functions/Lines
Iteration 9-10
输出 task_summary，结束循环
