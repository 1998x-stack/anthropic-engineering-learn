📖 Agent 定义尚未统一

AI Agent 具备三大核心能力：推理+行动、记忆系统、工具调用。但行业对术语仍缺乏共识。

推理 + 行动

使用 LLM 理解、执行和反思任务，结合 ReAct 等框架

记忆系统

短期记忆（上下文窗口）+ 长期记忆（向量数据库）

工具调用

通过外部 API 浏览网页、操作应用、读写文件、执行支付

典型案例

Apple 不提"AI"，公司不提"metaverse" —— 用户关心的是结果，不是技术。Saga AILindy.aiHeymoon 都在回避技术术语。

⚠️ 企业级可靠性差距

企业需要 99.9% 可靠性，但 Agent 面临测试、调试、延迟、监控等多重挑战。

"在传统 SW 工程中，200 毫秒就被认为很慢了。但对 Agent 和 LLM 应用来说，LLM 调用需要 30 秒以上。" —— Sully Omar, Cognosys CEO

当前挑战

测试困难；评估主观；调试非确定性；延迟过高；监控工具不足

发展方向

Agent 专用 SDK；标准化协议；Cloud sandbox 环境；垂直化聚焦

📊 垂直化是必然趋势

从通用 Agent 实验到特定领域的深度专精 —— 编码、个人助理、研究是三大热门方向。

编码

Sweep、GPT Engineer、Smol Developer —— 最热门的 Agent 应用场景

个人助理

Otherside、MultiOn —— 日常任务自动化

研究

Aomni 等 —— 商业智能和数据分析

"未来的软件将包含数十个服务于特定目的的'小型' AI Agent，它们相互交互。Agent 需要自己安全的云空间来自主地沟通和执行任务。"
