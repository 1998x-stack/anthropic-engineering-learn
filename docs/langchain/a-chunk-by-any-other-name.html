In its current configuration, the splitter aggregates the text of all elements with the same header metadata to a single document chunk—with the text of the related h4-level heading (if there is one) assigned to the metadata field "article_h4_subsection" and the text of each prior related heading assigned to the fields for h3, h2, and h1 respectively.
