Greetings, Llama Fans! 🦙

Welcome to this week’s edition of the LlamaIndex newsletter! We’re bringing you updates on new LlamaParse features, including Continuous Mode for multi-page table stitching and direct Excel output for seamless document processing. This edition also introduces our one-line deployment tool for financial analyst applications with create-llama, and a guide to building multi-agent report generation workflows with integrated human validation. Plus, don’t miss exciting use cases and tutorials from the community.

If you haven't explored LlamaParse yet, make sure to sign up and get in touch with us to discuss your specific enterprise use case.

- We have launched a one-line deployment tool with create-llama for building full-stack financial analyst applications that automate form filling ...

  • We have launched a one-line deployment tool with create-llama for building full-stack financial analyst applications that automate form filling tasks, such as populating CSVs or Excel files from financial reports. This open-source tool is powered by LlamaIndex workflows and includes a customizable Next.js frontend. Tweet.
  • LlamaIndex's chat-ui: Upgrade your AI projects with popular chat components from create-llama. This React component library features pre-built chat elements, Tailwind CSS customization, and easy integration with Vercel's AI library, including custom widgets, code and LaTeX styling, and a PDF viewer. Tweet.
  • We have integrated Cohere multi-modal embeddings, allowing you to combine images and text in the same vector space, and build effective Multi-Modal RAG applications. Docs, Tweet.
  • We have integrated Open Telemetry with Braintrust Data for enhanced logging and observability in LlamaIndex applications, allowing you to monitor complex, production environments effectively. Docs, Tweet.
