Finally, click “Advanced” and set an environment variable called NODE_VERSION to 20 . The default on Render is a much older version of Node so don’t skip this step!

There are several changes you need to make to the default configuration to successfully publish your static frontend:

- Name your site something memorable, it will become the URL of your site once it’s deployed - Set your root directory to frontend - Set your build command to npm install; npm run build - Set your publish directory to out - Finally, click “Advanced” and set an environment variable called NODE_VERSION to 20 . The default on Render is a much older version of Node so don’t skip this step!
