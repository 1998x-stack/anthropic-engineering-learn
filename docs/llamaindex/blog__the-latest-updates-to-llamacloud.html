⚙️ Increased Developer Collaboration

The team selection interface Organization settings

We’ve added organizational features into LlamaParse, enabling any individual user to create an organization and add other users to the organization. Any user within an organization will have a view of all the organization’s projects and indexes within each project.

This allows your team to have a single-source of truth for your data pipelines. In the past each developer would spend time re-indexing/experimenting with the same sources of data. This feature enables transparency, re-use, and generally more rapid development velocity.

📊 Improved Data and Metadata Access

We’ve made several updates here - we’ve added more data connectors and added features to let you more easily access and customize metadata.
