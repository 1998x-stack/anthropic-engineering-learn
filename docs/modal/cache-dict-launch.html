🔒 分布式锁去重

流量突增时，多容器竞争同一请求。skip_if_exists 实现 "exactly once" 语义。
Step 1: 获取锁
尝试写入 pending 状态，skip_if_exists 保证只有一个获胜
Step 2: 执行任务
.spawn() 启动 function call，更新为 in_progress
Step 3: 写入结果
完成后写入 completed 状态，后续请求直接读取缓存

效果验证

3 个相同请求：第 1 个执行计算，第 2 个被去重等待第 1 个完成，第 3 个直接从缓存返回。expensive function 仅被调用 1 次。
