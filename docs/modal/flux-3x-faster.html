⚙️ 标准优化 1.5x

Torch Compiler + Fused QKV + Channels-Last 三板斧。
🧠

Torch Compiler

TorchDynamo trace Python 字节码 → FX Graph → TorchInductor → Triton kernel。max-autotune 模式。

🔗

Fused QKV

将 Q/K/V 三个矩阵乘法合并为一个大矩阵乘法，暴露更多并行度。

💾

Channels Last

改变内存布局从 CHW 到 HWC，改善卷积操作的数据局部性。

🎨 First Block Caching：又一个 2x

Diffusion 模型迭代去噪过程中，某些步骤图像变化很小 -- 可以跳过！

近似计算的魅力

与传统程序不同，神经网络可以移除块或跳过步骤，程序仍然运行且结果 "几乎相同"。更像模拟计算机而非数字计算机。threshold=0.12 时获得 2x 加速且图像质量更好。

⚡ 冷启动：从十几分钟到秒级

Torch Compiler max-autotune 导致启动时间飙升。解决方案：缓存 + Memory Snapshots。

❌ 无缓存

每次启动重新编译，需要十几分钟。对 autoscaling 是灾难。

✅ 缓存 + 快照

Torch kernel cache + megacache + Modal Memory Snapshots，将 import torch 和 from_pretrained 变成单次文件读取。30x 冷启动加速。
