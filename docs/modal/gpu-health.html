❤️ 生命周期管理

被动监控（dmesg、DCGM）+ 主动健康检查（每周深度检查）。

被动监控

DCGM 定期检查、dmesg 错误（Xid errors）、温度/功率/时钟监控。Cloud C GPU 曾达 94C。

主动检查

每周：DCGM diag L2 + GPUBurn + NCCL all-reduce。失败则隔离整台主机。
