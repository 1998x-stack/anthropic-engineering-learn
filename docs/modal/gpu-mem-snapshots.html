💡 CPU 快照的 GPU 局限

之前的 CPU-only snapshot 需要在恢复后重新加载 GPU 状态，torch.compile 等操作无法跳过。

❌ CPU-only Snapshot

必须在 restore 后重新 CPU→GPU 拷贝权重。不能调用 torch.cuda.is_available()。torch.compile 必须重新运行。

✅ GPU Memory Snapshot

完整保存 GPU 状态：device memory、CUDA kernels、streams、contexts。恢复后 torch.compile 结果直接可用。

🧠 CUDA Checkpoint/Restore API

NVIDIA 新 API 让 GPU 内存状态可以被 checkpoint 和 restore。
1. Lock
cuCheckpointProcessLock() -- 锁定所有新 CUDA 调用，等待运行中的操作完成
2. Checkpoint
cuCheckpointProcessCheckpoint() -- 将 GPU 内存和 CUDA 状态复制到 host memory
3. CPU Snapshot
创建包含 CPU + GPU 内存的完整快照
4. Restore
cuCheckpointProcessRestore() + Unlock() -- 反向恢复所有状态
