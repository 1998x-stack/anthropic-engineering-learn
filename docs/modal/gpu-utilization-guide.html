📏 三种 GPU Utilization

同一个词 "GPU utilization" 指代三种跨数量级的完全不同度量。
📦

Allocation Util

GPU 运行应用代码的时间占比。关注 fleet 管理和 DevOps。

⚙️

Kernel Util

GPU 实际运行 kernel 的时间占比。nvidia-smi 报告的指标。

🧮

MFU

Model FLOP/s 吞吐量 / 理论 FLOP/s 带宽。最深层利用率。

📊 GPU Allocation Utilization

你付费的 GPU-seconds 中有多少在运行应用代码？行业平均 <70%，Modal 可达 90%+。

❌ 固定超额分配

预留集群在低谷期大量闲置，需求波动时无法快速调整。分配延迟导致 QoS 下降。

✅ Modal 弹性分配

多云 GPU 池 + 自定义容器栈（Rust）+ Memory Snapshot = 秒级启动，90%+ 利用率。

🔧 GPU Kernel Utilization

即使 GPU 在运行应用代码，也不意味着它在运行 GPU kernel。Host overhead 是主因。
数据移动
网络/磁盘 IO、模型下载、日志写入 -- 非 GPU 工作。
Host Overhead
CPU 无法足够快地给 GPU 分配工作。Python 在毫秒级开始跟不上。
优化方案
CUDA Graphs 批量启动 kernel + Dynamic Batching 聚合更多工作。

🧮 Model FLOP/s Utilization (MFU)

CEO 数学：GPU 支出本质上是浮点运算带宽的支出。

影响 MFU 的关键因素

  • 通信开销：节点间通信限制了大规模训练的 MFU
  • Memory Bandwidth：推理工作负载的算术强度低，受内存带宽限制
  • Kernel 质量：需要精心编写 kernel 才能充分利用 Tensor Core
