🔬 训练：从顺序到并行

Doppel 是 AI-native 社交工程攻击检测平台。威胁场景不断变化，模型迭代速度至关重要。

❌ 顺序实验 (Before)

实验按序执行，新假设等待前一个完成。失败时整个 run 报废。多个想法被打包进单次实验。

✅ Modal 并行 (After)

K-fold cross validation 各 fold 并发执行。.map() 分发独立实验。无需编排层。

🚀 推理：消除部署复杂度

从 Docker + Cloud Run + Flask 到 Modal 一行代码部署。
Before: Docker Build
大模型镜像构建 10-30 分钟，配置变更即触发重建
Before: Cloud Run
单 GPU 限制，冷启动延迟，流量突增时 provisioning 慢
Before: Flask 胶水
每个模型需要 HTTP 服务层（auth、序列化、路由）
After: Modal
Image layer caching + Volumes → 亚分钟构建。Serverless autoscale。直接调用。

🤖 Agent 增强实验循环

Agent 处理机械步骤（启动实验、收集指标），MLE 负责决定测试什么想法。
提出假设
→
Agent 运行实验
→
总结结果

"The limiting factor in our workflow is no longer infrastructure. It is simply how quickly we can generate and evaluate the next idea."
