💡 产品理念

给 Ramp 每个人 — 工程师、PM、设计师 — 无限并行工程容量

核心需求

启动速度与本地 Agent 一样快；深度集成 Ramp 技术栈（Sentry、Datadog、LaunchDarkly、Temporal）；零配置让任何人都能用。

🏗️ 技术架构

每个 Session 在 Modal Sandbox 中运行完整的全栈开发环境

Postgres + Redis
→
Temporal + RabbitMQ
→
OpenCode Agent
→
VS Code + VNC + Chromium

外部基础设施

Cron Functions 每 30 分钟构建快照；Queues 路由来自 Slack/Web/Chrome Extension 的 Prompt 到正确的 Session。

📸 文件系统快照：秒级启动

每 30 分钟克隆仓库、安装依赖、构建并保存快照 — 新 Session 从最新快照恢复

Slack、Web UI、Chrome Extension — 无需本地配置，支持多人协作

Slack 客户端

发送 Prompt 即触发

Web + VS Code

托管编辑器 + 流式桌面视图

Chrome Extension

非工程师可视化选择 UI 元素修改

📈 业务影响

非强制推广，产品说话 — 过半合并 PR 来自 Inspect

PM 可直接给产品添加功能。设计师实现意图与实现之间的紧密反馈。工程师专注于高影响力、高复杂度的工作 — 比如构建 Inspect 本身（80% 由 Inspect 自己编写）。

"Modal 让构建这一切变得非常容易。第一个版本只花了我几天就搞起来了，它有我们需要的所有正确 API 来构建我们所需规模的东西。"

— Zach Bruggeman, Ramp 工程师
