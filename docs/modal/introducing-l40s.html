🚀 为什么需要 L40S

AI Inference 有独特的基础设施需求——L40S 正是为此而生的 Ada Lovelace 架构加速器

推理场景的核心痛点

Modal 团队认为 AI Inference 的基础设施需求与训练有着本质区别：需要更灵活的 GPU 容量、更快的冷启动、更高效的 autoscaling。L40S 作为当前最受欢迎的推理加速器 A10 的升级版，在显存容量和计算带宽上实现了质的飞跃。

❌ A10 的局限

  • 24GB 显存限制了大模型运行
  • Ampere 架构不支持 FP8
  • 内存带宽仅 600 GB/s
  • 运行 Flux.1-schnell 16bit 会 OOM

✅ L40S 的优势

  • 48GB DDR6 — 2x 显存容量
  • Ada Lovelace + FP8 Tensor Cores
  • 864 GB/s 内存带宽
  • 轻松运行 Flux.1-schnell 全精度

💾 更大模型支持

48GB 显存意味着可以在单卡上运行更大的模型，无需痛苦的 CPU Offload

Flux.1-schnell 实测

以 Flux.1-schnell 为例，16bit 精度下仅模型权重就占用 24GB，在 A10 上无法运行（触发 CUDA OOM），但在 L40S 上运行非常从容。这意味着开发者不再需要牺牲 throughput 来做 CPU RAM offload。

⚡ 推理速度提升

不仅是显存更大——L40S 在计算速度上同样大幅领先

性能基准测试

Memory-bound 任务（如小 batch inference）可获得约 40% 加速；Compute-bound 任务（使用 16bit Tensor Cores）加速超过 100%。在 chat-style workload 的基础 load test 中，无需任何调优即可实现 20% 加速。
