🎬 公司背景

Lemon Slice 致力于构建世界上最具表现力的 AI 角色生成模型

Lemon Slice 的第一个病毒式产品允许用户输入一张角色图片加文本/音频，即可生成角色说话的视频。创始团队来自 ML 研究背景，之前在 AWS 和 GCP 上搭建过自定义基础设施——配置实例、跨区域计算、构建扩展逻辑——这些经历让他们不想重蹈覆辙。

"Modal allowed us to go from an idea on Monday to something live on Tuesday. From 70% of an engineer's time spent in infrastructure to like, less than 10%, that's a huge delta." — Lina Colucci, CEO

⚡ 可扩展推理

两个 Modal Functions 即可扩展到 10,000 请求/小时

架构简洁性

使用 Modal，Lemon Slice 只需编写两个 Python Functions：一个作为用户输入的 REST endpoint，另一个在 GPU 上运行视频模型推理。

🎯 低延迟优化

结合 Modal、Pipecat 和 Daily 的低延迟特性，实现 3-6 秒端到端响应

✅ Modal Tunnel

容器间使用 TCP 端口直连，绕过额外网络层

✅ Region Selection

确保 Pipecat 容器和推理容器地理位置相邻

💡 关键启示

从 Lemon Slice 的实践中提炼的可复用经验

  • 基础设施解耦：将复杂的 ECS/Queue/LB 架构替换为简洁的 Modal Functions
  • Autoscaling 内置：Modal 根据请求量自动扩缩容 GPU 容器
  • Memory Snapshot：内置的内存快照功能减少容器初始化时间
  • 实时管道：Pipecat + Modal Tunnel + Daily WebRTC 的组合实现了低延迟实时 AI
