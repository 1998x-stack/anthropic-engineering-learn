💡 Modal 为什么适合

CPU 容器运行有状态 Bot，GPU 服务按需 Autoscale——分离计算与推理

Pipecat Bot 只需 CPU 即可高效运行，而 GPU 推理服务可独立 autoscale。Modal 让你用 CPU 容器运行有状态的 Bot 进程，同时按需调用 GPU 服务——这意味着显著的成本节省。

🌐 网络延迟优化

WebRTC、Modal Tunnels 和 Region Pinning 三管齐下

Client ↔ Bot: WebRTC
Pipecat 的 SmallWebRTC 层管理浏览器到 Bot 的实时连接
Bot ↔ 推理服务: Modal Tunnels
绕过 Modal input plane，WebSocket 直连 STT/TTS 服务
Region Pinning
将 Bot 和 AI 服务固定到同一数据中心集群，减少物理距离

关键发现：确保 Bot 和 Modal 推理服务在相邻数据中心比 Client 与 Bot 的距离更重要；不使用 Tunnels 时应部署在 us-east（靠近 input plane）。
