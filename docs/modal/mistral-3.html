📸 GPU Snapshotting

Alpha 阶段的突破性功能——将 GPU 内存状态也纳入快照

工作原理

启用 Sleep Mode 后，vLLM 服务器首次初始化完成后会被休眠，GPU 内存内容转移到 CPU 内存以便快照。后续启动从快照恢复，跳过昂贵的 Torch 编译和模型加载。

experimental_options={"enable_gpu_snapshot": True}
