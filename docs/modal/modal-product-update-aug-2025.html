🤖 Service Tokens

Workspace Manager 可创建独立的 Service Users 和 API Tokens

不再依赖特定成员的 tokens 来自动化 Modal Apps 部署。Service Users 拥有独立的 API tokens，适合 CI/CD 集成。

🏃 浏览器运行 Functions (Beta)

Modal 根据类型注解自动生成 Function UI

部署后可直接在浏览器中测试和调试 Functions，也可作为触发内部工作流的用户友好界面。要求 client v1.1+，所有参数需有类型注解。
