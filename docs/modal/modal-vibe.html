🪩 Vibe Coding 的崛起

运行不可信的 LLM 代码需要安全、可快照的运行时环境

从 AI Code Review 到 Coding Agents，运行不可信 LLM 代码已成为常态。如果想在不被 "seriously harsh your vibe" 的前提下运行这些工作流，你需要像 Modal Sandboxes 这样的安全运行时。
