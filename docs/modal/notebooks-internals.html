⏸️ 调度与容量

空闲自动暂停、秒级恢复——持久体验而无持久成本

Kernel 空闲时自动暂停，回来时秒级恢复。获得持久机器的体验，但没有闲置成本。

🗃️ VolumeFS 存储

文件树在 Spanner 中、最终一致性操作、分布式 CDN 复用

VolumeFS 是 Modal Volumes 的核心——一个为全球访问设计的 FUSE 文件系统，存储 PB 级数据。文件感觉像本地的，但行为是全局的。
