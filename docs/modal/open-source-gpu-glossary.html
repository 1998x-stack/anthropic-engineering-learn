📖 为什么写 GPU Glossary

GPU 编程很难——比它需要的更难，因为缺少高质量的跨栈参考材料

GPU 编程的困境

高性能计算本身就很难——性能会打破抽象、难以调试、是相对和竞争性的。但更难的是缺乏像高质量教科书那样跨越整个栈、编织连贯图景的参考材料。

🌐 为什么开源

社区贡献需求 + 邮件/社交媒体的吞吐量限制

Modal 收到了大量贡献请求——错别字修正、小改正、完整新章节、eBook 编译。通过邮件和社交媒体处理这些请求的吞吐量有限，开源到 GitHub 可以更好地处理贡献，也允许他人 fork 使用。
