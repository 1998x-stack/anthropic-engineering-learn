🤖 Pi 简介

构建通用机器人智能系统——VLA 架构驱动的闭环连续推理

Physical Intelligence (Pi) 的核心模型是 Visual-Language-Action (VLA) 架构，接受视觉观察、自然语言指令和机器人本体感觉状态，输出下一个瞬间的电机命令。每个手臂运动都经过这个连续推理的闭环。

⏱️ 实时推理挑战

机器人处于连续控制循环中——即使微小的抖动或阻塞都会降低行为质量

标准方案是在机器人上搭载 GPU 进行本地推理。但远程推理可为没有板载 GPU 的机器人提供更轻量的方案，同时能使用数据中心级别的更大 GPU 来实验更大模型。

🔌 Modal Tunnels

直接 TCP 端口暴露——大多数低延迟场景的标准方案

Tunnels 在不到一分钟的容器启动时间内，通过自动 TLS 终止和安全 URL 将运行中容器的 TCP 端口暴露到公网。适用于 API、Jupyter Notebooks、VS Code 等交互式工作负载。

🚀 QUIC 传输方案

基于 UDP 的 QUIC Portal——Rust 实现，自动 NAT 穿越

技术细节

  • 持久双向通道——机器人连接一次，持续流式传输观察和接收动作
  • STUN 发现 + UDP 打洞的自动 NAT 穿越
  • 通过 Modal Dict 进行会合协调
  • Rust 实现的 QUIC，高吞吐低延迟
  • 仅增加 ~10-15ms 网络开销

📍 Region Pinning

将推理部署固定到靠近机器人的区域——最短往返路径

Checkpoint 存储在 Modal Volumes 中，直接挂载到 GPU 容器。模型加载不到 30 秒。

🌎 全球扩展

新增机器人位置不再需要基础设施建设——同一容器、同一 Checkpoint、同一传输

在新位置附近启动相同容器，通过 Modal Volumes 挂载相同 Checkpoint，使用相同的低延迟传输连接机器人——无需运送 GPU 塔或搭建本地集群。
