📁 Directory Snapshots

精确快照特定目录——分离系统依赖与应用代码，加速初始化

此前快照 Sandbox 意味着捕获整个文件系统。Directory Snapshots 允许快照特定目录并独立于基础镜像挂载到新 Sandbox 中。
