❓ Quora 和 Poe

4 亿月活的 Q&A 平台 + AI 聊天机器人平台 Poe

Quora 是拥有 4 亿月活用户的知识分享平台。2023 年推出 Poe——一个 AI 聊天机器人平台，任何人都可以部署公共聊天机器人。Quora 已为 Poe 融资 $75M。

🔧 代码解释器需求

安全性 + 低延迟 + 可靠性——三大核心需求

Poe 中的 LLM 机器人可以生成代码，用户期望直接在 Poe 中运行而非复制到编辑器。团队需要完全隔离的安全代码执行方案。

💡 为什么选择 Modal

自建需要数月且还需持续投入——Modal 开箱即用

自建方案

  • 数月开发时间
  • 安全隔离需持续维护
  • 可扩展性自行构建
  • 网络限制自行实现

Modal Sandboxes

  • 即插即用
  • gVisor 企业级隔离
  • 1000 Sandbox/秒创建
  • 内置 Tunnels 和 IP 限制

🏗️ Modal Sandboxes 优势

核心原语 Modal Functions 减去 Modal Client——战斗测试过的成熟产品

  • ✅ gVisor 的企业级容器隔离
  • ✅ 压力测试通过 1000 Sandbox/秒的创建吞吐量
  • ✅ Tunnels 和 IP Allowlisting 等强大网络原语

"There would be a lot of edge cases and unknowns if we built code sandboxes ourselves... We offloaded this to Modal and are actively saving 2 engineers' worth of ongoing engineering time." — Hwan Seung Yeo, Director of Engineering

🚀 快速上手

三步开始使用 Modal Sandboxes

# 安装 Modal pip install modal # 创建账号 python -m modal setup # 开始使用 Sandboxes import modal sb = modal.Sandbox.create( "python", "-c", "print('Hello from sandbox!')" ) sb.wait()
