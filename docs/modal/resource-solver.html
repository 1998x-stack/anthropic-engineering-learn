⚖️ 双重使命：速度 vs 成本

像美联储一样，Modal 的扩容决策必须同时追求快速响应和成本最优

⏱️ 速度优先

  • 用户期望秒级调度容器
  • 维护 Buffer 应对突发
  • 求解时间必须可控

💰 成本优化

  • 最小化 GPU 空闲
  • 捕捉云价格套利
  • 剪枝实例类型加速求解

实际优化手段

在运行 GLOP 之前用廉价启发式算法预处理输入：剪枝冗余实例类型可将求解时间缩短一个数量级（从数分钟降至亚秒级），仅牺牲少量精度。
