可以把 FA4 想象为对 Key-Value 存储的向量化顺序扫描，为一批聚合查询（Query Tiles）服务。每个 CTA 的工作类似于微服务架构图。

🧬 数学创新：快速近似指数函数

用 CUDA Core 上的三次多项式替代 SFU 的硬件指数运算，避免 SFU 排队瓶颈

算法思路（Schraudolph 1999 启发）

将 2^x 分为整数部分 2^floor(x) 和小数部分 2^(x-floor(x))。对 [0,1] 区间用三次多项式 Horner 评估：

0.07711909*r^3 + 0.22756439*r^2 + 0.69514614*r + 1.0

三个 FMA 指令完成，对 bf16 精度与 SFU 输出完全匹配。

→

→

→
2^x 结果 (f32x2)

📊 智能 Online Softmax

不再每次新最大值出现就触发校正，而是仅在影响数值稳定性时才更新，校正次数减少 10 倍

FA3 之前

  • 每次发现新 max 都触发 Correction
  • Correction 频率高，浪费大量计算
  • 所有指数运算都走 SFU

FA4 改进

  • 仅当 max 变化"足够大"时才校正
  • Correction 减少 ~10x
  • 部分迭代用 CUDA Core 近似指数

🔬 五种 Warp 角色深入

从 Load 到 Epilogue，每种 Warp 在 Pipeline 中承担特定职责

Load Warp

使用 TMA 异步加载 2 个 Q Tile，并流式加载所有 K/V Tile（最多 3 对 buffer）

MMA Warp

用 tcgen05.mma 指令在 Tensor Core 上执行矩阵乘，产生 S 和 O Tile

Softmax Warps (8)

两个 Warpgroup 归一化注意力分数，在 Register 和 Tensor Memory 间复制数据

Correction Warps (4)

监控缩放因子变化，仅在数值稳定性受威胁时才重缩放输出 Tile

Epilogue Warp (1-2)

将完成的 Output Tile 从 Tensor Memory 存回 Global Memory，可选 TMA 加速
