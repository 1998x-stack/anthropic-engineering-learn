🛡️ 为什么构建 Sandboxes

Agent 系统需要在没有人工监督的情况下执行代码，你不能像信任自己一样信任 LLM

❌ 风险场景

  • Agent 可能犯破坏性错误
  • 恶意用户可能注入危险 Prompt
  • LLM 代码不应访问你的资源

✅ Sandbox 方案

  • 动态环境运行任意语言
  • 与 Modal 资源安全隔离
  • exec API 简洁易用

💻 核心 API

简洁的 exec API + 灵活的 Image 配置 + 文件系统快照

运行时环境配置

LLM 可能需要特定依赖或其他语言执行。Sandbox 支持与 Functions 相同的 Image API 在运行时配置环境。
