🔒 SOC 2 Type II 是什么

SOC 2 是最广泛认可的信息安全合规标准之一，Type II 比 Type I 更严格。

Type I

评估某个时间点的安全态势，是合规的第一步。Modal 已于此前完成。

Type II

评估一段时间窗口内的安全控制措施，更全面更严格。零偏差通过审计。
