🎙️ 公司与产品

Zencastr 是领先的播客平台，为数千创作者提供录制、制作和托管服务

核心产品包括 AI 语音转写（强制对齐、逐字词、时间戳等），从 CPU 模型迁移到 Whisper 等 Transformer 模型以获得更好质量。

🚧 Kubernetes 困境

GPU 节点常驻成本高，多模型依赖管理脆弱

❌ Kubernetes 问题

  • 流量尖峰但 GPU 节点必须常驻
  • 夜间/假日严重过度分配
  • 不同模型需要不同 Torch/TF 版本
  • GPU 驱动版本同步脆弱

✅ Modal 优势

  • 真正的 Scale-to-Zero
  • 程序化定义 Image 管理依赖
  • 预装 CUDA 驱动自动更新
  • 灵活尝试不同 GPU 型号和并发

🔧 Modal 解决方案

所有核心 ML 工作负载运行在 Modal 上

AI 转写

平台上每个播客的语音识别

Speaker 分析

说话人计数和笑声检测

音频增强

音质评分和后期制作

🔥 1500 GPU 批处理

分钟级扩容到 1500 并发 GPU，丰富全部历史播客内容

S3 Gateway 下载音频
→
Modal Volume 存储
→
多 Function 并行提取特征

1500 GPU 峰值

单次运行中，Zencastr 在分钟内扩容到 1500 并发 GPU 来丰富所有播客内容。尽管规模巨大，Modal 基础设施全程稳定。无需额外 DevOps 工作。
