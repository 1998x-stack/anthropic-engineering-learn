## Breakout sessions

### Untrusted code, unprecedented speed: High-velocity runtimes for AI agents

LangChain will be featured in a breakout session at Google Cloud Next on building high-performance, secure runtimes for AI agents.

The session explores how to scale agent infrastructure while safely running untrusted, LLM-generated code, covering techniques like subsecond cold starts for massive concurrency and using gVisor for kernel-level isolation in zero-trust environments. It will also highlight how these approaches power real-world AI agent systems in production.

Eric Johanson joins as a customer speaker, sharing how LangChain leverages this architecture to run and scale autonomous agents securely on Google Cloud.

## Panel discussion

### The future of developer experience is frictionless

LangChain joins Atlassian, Datadog, Harness, and Google Cloud to explore how AI agents and open standards are eliminating friction across the developer lifecycle.

Fragmented tools and siloed workflows slow teams down. This session looks at how AI agent interoperability and open standards are enabling a more seamless, “anti-gravity” developer experience, reducing context switching and accelerating delivery across the stack.

**Moderator:**

- Utkarsh Guleri, Head of DevEx, AIOps &amp; Database Tech Partnerships @ Google Cloud

**Speakers:**

- Don Baron, Head of Product Partnerships, Atlassian
- Pulkit Chandra, Product Management Leader, Datadog
- Nick Durkin, Field CTO, Harness
- Karan Singh, Partnerships Lead, LangChain

**You’ll learn:**

- How interoperable AI agents streamline workflows across platforms
- How open standards reduce integration overhead and vendor lock-in
- Practical ways to build faster, more cohesive developer pipelines
- What’s next for DevEx in an agent-driven world

## LangSmith on Google Cloud Marketplace

LangSmith is now available in the Google Cloud Marketplace, making it easier for teams building on Google Cloud to procure and deploy LangChain’s platform for AI agents.

With Marketplace availability, organizations can purchase LangSmith through their existing Google Cloud account, apply it toward committed cloud spend, and simplify procurement through consolidated billing.

LangSmith helps teams debug, evaluate, and monitor AI applications, providing visibility into agent performance and production behavior.
