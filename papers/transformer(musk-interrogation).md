# 马斯克式决策审问：注意力即一切——Transformer 的诞生

> **分析对象**: [Attention Is All You Need](https://arxiv.org/abs/1706.03762) (Vaswani et al., NIPS 2017)
> **分析框架**: Musk-Style Decision Interrogation
> **角色**: Ashish Vaswani, Noam Shazeer, Niki Parmar, Jakob Uszkoreit, Llion Jones, Aidan N. Gomez, Łukasz Kaiser, Illia Polosukhin（共同一作，Google Brain/Research）

## 问题一：你的故事——你做了什么决策，为什么？

2017 年，序列建模的世界被 RNN 统治。LSTM、GRU——这些是机器翻译、语言建模、任何序列到序列任务的基石。大家都在优化递归单元的内部结构、加注意力机制作为辅助、用分解技巧加速训练。

我们做了一件当时看来近乎疯狂的事：**把递归全部扔掉。** 整个模型不包含任何循环连接、任何卷积、任何序列对齐的计算。这是纯粹的注意力机制——从输入到输出，每一步都是并行的矩阵乘法。

主流意见是：递归对序列建模是必需的——序列的顺序信息必须通过逐步传递来捕捉。我们说：不需要。

### 决策一：完全放弃递归和卷积——用注意力替代一切

**主流做法是什么？**

2017 年最好的序列转导模型（机器翻译等）都基于 RNN 的编码器-解码器架构。编码器按序读入输入，生成隐状态序列；解码器按序生成输出，每一步依赖上一步的隐状态。注意力机制被引入作为**辅助**——帮助解码器关注编码器的相关部分。但核心计算仍是递归的。

递归的物理限制很明显：**计算是序列化的。** 位置 t 的计算必须等位置 t-1 完成。你无法在训练样本内并行化——每个 token 必须等前一个 token 处理完。长序列时，内存限制约束了跨样本的批处理。分解技巧和条件计算能改善效率——但**序列化计算的根本约束依然存在。**

卷积网络被用来替代递归（ByteNet、ConvS2S）——它们可以在所有位置上并行计算。但代价是：连接两个任意位置所需的操作数随它们之间的距离增长——线性或对数增长。这使得学习长距离依赖更难。

**我们如何从第一性原理拆解这个问题：**

序列转导模型的核心需求是什么？

1. **映射变长输入到变长输出**
2. **捕捉 token 之间的依赖——无论它们相距多远**
3. **高效训练——计算应该可并行化**

RNN 能做好 (1) 和 (2)——但 (3) 是致命缺陷。卷积能做好 (1) 和 (3)——但 (2) 随着距离衰减。

注意力机制呢？注意力的本质是：**给定一个 query，在所有 key 上计算相关性权重，用这些权重对 values 加权求和。** 这个操作——

- 不需要序列化：所有位置的注意力可以同时计算
- 路径长度恒为 O(1)：任何两个位置之间的信息流只需一步
- 复杂度 O(n² · d)：序列长度的二次方——但在 n < d 时（机器翻译的典型情况），这比 RNN 的 O(n · d²) 更快

**我们的反直觉决定：**

不是"把注意力作为 RNN 的辅助"——是"用注意力替代 RNN"。编码器：堆叠的自注意力层（每层中每个位置关注所有其他位置）。解码器：带掩码的自注意力（防止看到未来位置）+ 编码器-解码器注意力。**没有循环。没有卷积。只有注意力。**

**为什么我们确信这是对的：**

因为自注意力的 O(1) 路径长度是一个物理优势——不是调参能替代的。在 RNN 中，信息从位置 1 流到位置 n 需要穿过 n 个递归步骤——每一步都有信息损失。在 Transformer 中，位置 1 和位置 n 在单次注意力操作中直接连接。梯度不需要穿过 n 层才能到达——它直接穿过注意力矩阵。

我们不是在优化现有架构中的一个小问题——我们在消除整个信息瓶颈。

**实验验证了我们的信念：**

在 WMT 2014 英德翻译上，基础模型训练 12 小时（8 块 P100 GPU）就超过了所有已发表的模型和集成。大模型达到 28.4 BLEU——比之前的最佳结果（包括集成模型）高出 2 个 BLEU。在英法翻译上，41.8 BLEU 的新纪录，训练成本只有之前最优模型的 1/4。

### 决策二：缩放点积注意力——消除大维度下的梯度灾难

**直觉做法：**

点积注意力已经存在——它只是 query 和 key 的点积 → softmax → 对 value 加权。简单。加性注意力（Bahdanau attention）用一个单隐层前馈网络计算兼容性函数——理论上没有维度限制。

**我们发现了什么：**

对于小的 dk，点积注意力和加性注意力表现相似。但当 dk 变大时——**点积注意力会失败。** 为什么？

因为如果 q 和 k 的每个分量是独立的随机变量（均值 0，方差 1），它们的点积 q·k 的方差是 dk。当 dk = 512 时，点积值的幅度变得非常大——把 softmax 推到梯度极小的区域。

**我们的硬伤修复——乘以 1/√dk：**

不改变注意力机制的本质——只是在 softmax 之前除以√dk。把点积的方差从 dk 拉回 1。梯度回来了。大维度下也能工作。

```
Attention(Q, K, V) = softmax(QK^T / √dk) V
```

这不是一个花哨的改动——这是一个**梯度健康度的物理修复。** 没有它，你在 dk > 64 时训练会崩溃。有了它，你可以任意扩展 dk（受限于计算资源）。

**这个修复的启示：**

架构创新不总是大的、花哨的。有时候——最具影响力的改进是在正确的位置除以正确的数。

### 决策三：多头注意力——不是"一个大的"而是"多个小的并行"

**直觉做法：**

用 dmodel = 512 维的 key、query、value 做一次注意力。

**为什么这不够：**

单个注意力头对所有位置取平均——它只能从单个"表示子空间"中提取信息。但语言中的依赖是多维度的：一个 token 可能同时与句法上相关的 token（主语-动词）、语义上相关的 token（指代消解）、位置上相关的 token（相邻词）有不同的关注模式。

**我们的方案：**

h = 8 个并行的注意力头。每个头把 Q、K、V 线性投影到 dk = dk = dv = dmodel / h = 64 维。在各自的投影子空间中独立计算注意力。然后拼接所有头的输出，再做一次线性投影。

```
MultiHead(Q, K, V) = Concat(head_1, ..., head_h) W^O
head_i = Attention(Q W^Q_i, K W^K_i, V W^V_i)
```

**为什么 8 个头：**

因为 512/8 = 64——每个头的维度降低使得**总计算成本与单头全维度注意力相当。** 这不是"免费的多头"——你用更小的矩阵乘法换来了多个表示子空间。

实验验证：单头注意力比最优配置低 0.9 BLEU（表 3 行 A）。头太多（16、32）也会降低质量——可能是因为每个头的维度太小（32、16），无法捕捉足够的表示信息。

**这个设计的物理本质：**

多头注意力不是"8 个独立的注意力彼此不知道对方在做什么"——它们是**在同一批输入上从不同角度同时计算注意力。** 最终通过 W^O 矩阵融合——学习如何组合来自不同子空间的信息。

事后看注意力的可视化：不同头确实学会了关注不同类型的关系——有些头关注句法结构，有些关注语义关联，有些关注位置邻近关系。这不是我们编程的——这是模型自己学到的。

### 决策四：正弦位置编码——不用可学习的，用固定的

**直觉做法：**

让模型学习位置嵌入——就像学习 token 嵌入一样。每个位置有一个可学习的向量，在训练中更新。

**我们为什么选了正弦函数：**

我们测试了两种方案——可学习的位置嵌入和固定的正弦位置编码。**结果几乎完全一样**（表 3 行 E：4.92 vs. 4.92 perplexity，25.8 vs. 25.7 BLEU）。

但我们选了正弦。为什么？因为正弦函数有一个可学习嵌入没有的属性：**外推能力。** 可学习嵌入只能编码训练时见过的位置（如 0 到 512）。正弦编码可以编码任意长度的位置——因为它是连续函数。

```
PE(pos, 2i)   = sin(pos / 10000^(2i/dmodel))
PE(pos, 2i+1) = cos(pos / 10000^(2i/dmodel))
```

不同维度对应不同频率的正弦波——波长从 2π 到 10000 · 2π，形成几何级数。这个设计基于一个假设：**对于任何固定偏移 k，PE(pos+k) 可以表示为 PE(pos) 的线性函数。** 这意味着模型可以通过线性变换学会关注相对位置。

在实践中——虽然可学习编码和我们选了正弦——但正弦的数学优雅和外推潜力让我们更安心。这是一个"两种都行，但我选未来更灵活的"的决策。

### 决策五：层归一化 + 残差连接——偷来的但用得极致

**我们偷了什么：**

残差连接——何凯明 2016 年的 ResNet。层归一化——Ba 等人 2016 年。

**我们怎么用的：**

每个子层（自注意力、前馈网络）的输出 = LayerNorm(x + Sublayer(x))。不是 Sublayer(LayerNorm(x))——是 LayerNorm(x + Sublayer(x))。残差连接在前，归一化在后。

这与后来的 Pre-LN Transformer（先归一化再子层）不同——但事后证明，我们的 Post-LN 设计在当时是训练深网络的关键。

6 层编码器 + 6 层解码器——没有残差连接和层归一化，这么多层根本训练不起来。梯度会在深层中消失或爆炸。残差连接提供了恒等映射的"梯度快速通道"——允许信号和梯度直接穿过深层。归一化稳定了每层的激活分布。

**这不是我们的原创——但这是我们的工程判断：** 知道哪些现有的技术可以组合起来使你的新架构可行，与发明新架构本身一样重要。

## 问题二：你解决过最难的问题是什么？

### 情境与任务

2016-2017 年，序列建模的世界被 RNN 支配。LSTM 和 GRU 是机器翻译、语言建模的标准答案。每个模型都有一个编码器（逐 token 读入）和解码器（逐 token 生成）。注意力机制被引入作为 RNN 的辅助——帮助解码器在生成时关注编码器的相关部分。

核心物理限制：**RNN 是序列化的。** 位置 t 的计算必须等待位置 t-1 完成。你无法在训练样本内并行化。长序列时——每次只能处理很少的样本，因为内存限制。

这意味着：训练慢、梯度流动长、长距离依赖难以学习。

行业在尝试两个方向：用卷积替代递归（并行化但路径长度随距离增长），用注意力辅助递归（改善依赖捕捉但没有解决并行化）。

我们的任务：**构建一个序列转导模型，同时满足三个条件：完全可并行化、恒定路径长度的长距离依赖、训练速度远超现有方案。**

### 行动

**失败的直觉——注意力作为辅助：**

第一反应自然是在 RNN 上加大注意力。Bahdanau 等人 2014 年已经展示了注意力的价值。让注意力更复杂——层级注意力、结构化注意力、多头注意力辅助 RNN。

但这解决的是症状（长距离依赖难以学习），不是根因（递归本身就是信息瓶颈）。你在一个序列化的架构上加上并行的注意力——但核心计算仍是序列化的。训练仍然慢。梯度仍然需要穿过递归步骤。

**亲手解剖——为什么自注意力能工作：**

我们没有从"RNN 加什么"出发——我们从"序列转导模型需要什么函数"出发。

一个序列转导层的基本操作是：把输入序列 (x1, ..., xn) 映射到输出序列 (z1, ..., zn)，其中每个 zi 是输入序列所有元素的函数。RNN 通过递归传递信息来完成这个映射——zi 从 xi 和 hi-1 计算，其中 hi-1 本身包含了之前所有 x 的信息。

但在数学上——**递归只是实现这个函数的一种方式，不是唯一的方式。** 如果你不需要序列化——你可以让每个 zi 直接关注所有的 x_j。

这就是自注意力：zi = weighted_sum(所有 xj)，权重 = softmax(qi · kj / √dk)。

**洞察时刻——路径长度的物理意义：**

盯着 RNN 和自注意力的复杂度表，一个数字跳了出来：**最大路径长度。**

RNN：O(n)——从位置 1 到位置 n 的信号需要穿过 n 个递归步骤。

卷积（标准）：O(n/k)——堆叠多层卷积才能连接远距离位置。

ByteNet（空洞卷积）：O(log_k(n))——比标准卷积好，但仍随距离增长。

**自注意力：O(1)。** 任何两个位置——不管相距多远——只需一步操作直接连接。

这不是渐近分析的学术游戏。这是梯度流动的物理现实。在 RNN 中，来自位置 n 的梯度要穿过 n 层才能影响位置 1 的表示——梯度会衰减、会爆炸、会丢失信息。在自注意力中——梯度直接穿过注意力矩阵。一步。

**这就是为什么 Transformer 能学会长距离依赖——不是因为"注意力机制很聪明"，是因为路径长度是恒定的。**

### 破坏性解决方案——全注意力架构 + 训练效率的阶跃提升：

不是给 RNN 加注意力——是用注意力彻底替代 RNN。

架构：

- 编码器：6 层，每层 = 多头自注意力 + 位置前馈网络。残差连接 + 层归一化包裹每个子层。
- 解码器：6 层，每层 = 掩码多头自注意力 + 编码器-解码器多头注意力 + 位置前馈网络。
- 位置编码：正弦函数，加到输入嵌入上。
- 缩放点积注意力：除以√dk 防止大维度下的梯度消失。
- 多头注意力：h = 8，每个头 dk = dv = 64。

训练：
- 8 块 P100 GPU，基础模型每步 0.4 秒，100K 步 = 12 小时。
- WMT 2014 英德：4.5M 句子对。
- WMT 2014 英法：36M 句子对，大模型训练 3.5 天。

### 结果

| 指标 | 之前 SOTA | Transformer | 训练成本对比 |
|------|-----------|-------------|-------------|
| EN-DE BLEU | 26.36 (集成) | 28.4 (单模型) | 3.3×10¹⁸ FLOPs (base) |
| EN-FR BLEU | 41.29 (集成) | 41.8 (单模型) | 之前 1/4 |
| 训练时间 | 数天到数周 | 12小时 (base) / 3.5天 (big) | 数量级下降 |
| 英语句法分析 (WSJ 23 F1) | 91.7 (RNNG) | 92.7 (半监督) | 超越任务专用模型 |

**最被低估的结果——句法分析：**

Transformer 在只有 40K 训练句子的 WSJ 上达到了 91.3 F1——超过了 BerkeleyParser（专门为句法分析设计的模型）。RNN 序列到序列模型在小数据上一直不如专门设计的解析器。Transformer 没有这个问题——因为自注意力的归纳偏置（全局依赖 + 结构化注意力模式）恰好与句法分析的需求对齐。

**我必须承认的局限（论文中自述）：**

自注意力的复杂度是 O(n² · d)——对长序列是瓶颈。对于 n >> d 的任务（如高分辨率图像、长文档），这不可行。我们提出了受限自注意力（只关注大小为 r 的邻域）作为未来方向——但这会增加路径长度到 O(n/r)。

位置编码的绝对 vs. 相对——我们用的是绝对正弦编码，但学界后来发展了更好的相对位置编码方案（如 Transformer-XL、RoPE），证明绝对位置编码不是最优解。

我们没有预见到这个架构会成为整个 AI 领域的基础——从 GPT 到 BERT 到 ViT 到多模态模型。我们当时只是想做更好的机器翻译。

---

*这个分析用第一性原理拆解了 Transformer 架构的核心决策——不是"注意力怎么和 RNN 结合"，而是"递归的序列化计算是物理瓶颈，注意力可以完全替代它"。关键洞察：自注意力提供 O(1) 的最大路径长度——任何两个位置只需一步操作连接——这是梯度流动的物理优势，不是渐近分析的学术游戏。缩放点积注意力的 √dk 修复了大维度下的梯度消失。多头注意力通过并行的低维投影在多个表示子空间中同时捕捉关系。正弦位置编码提供了可学习嵌入不具有的外推能力。以及最关键的教训：有时候最具影响力的改进不是在现有架构上加东西——是把整个旧架构扔掉。*
